# Project: Todo List

## About
This is another project asigned to me by [The Odin Project](https://www.theodinproject.com).


## Goal

Each todo item will be an object. Each object will contain a title, description, due date and priority along with a note providing a description of the todo item. 

Each todo list will be put into the default Project section but can otherwise be put into other sections if the user specifies so. 

Remote storage API will be used for offsite note storage, but also localStorage will be used.
